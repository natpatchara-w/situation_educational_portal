## 7. Things to Bring

### Personal Essentials

- [ ] Student ID and government ID.
- [ ] Phone, charger, and power bank.
- [ ] Water bottle.
- [ ] Personal medication.
- [ ] Appropriate clothing and footwear.
- [ ] Rain protection.
- [ ] Cash in small denominations.
- [ ] Offline map or saved route screenshots.

### Health and Safety

- [ ] First-aid kit.
- [ ] Mask and hand sanitizer, if needed.
- [ ] Motion sickness medicine, if needed.
- [ ] Mosquito repellent or sunscreen, if relevant.
- [ ] Emergency contact card.

### Activity Materials

- [ ] Printed/offline agenda.
- [ ] Activity script or facilitator guide.
- [ ] Props or teaching materials.
- [ ] Stationery.
- [ ] Prizes or tokens, if approved.
- [ ] Trash bags.

### Documentation Kit

- [ ] Camera or phone with enough storage.
- [ ] Power bank or extra battery.
- [ ] Shot list.
- [ ] Consent guidance.
- [ ] Backup/upload plan.

## 8. Preparation Timeline

### One Week Before

- [ ] Confirm schedule, location, transport mode, and local contacts.
- [ ] Assign volunteer roles.
- [ ] Review event materials.
- [ ] Prepare activity materials.
- [ ] Confirm participant profile and expected number.
- [ ] Review safety and conduct guidance.

### 2-3 Days Before

- [ ] Reconfirm venue readiness.
- [ ] Reconfirm transport details.
- [ ] Print or save offline documents.
- [ ] Test equipment.
- [ ] Pack materials by session or role.
- [ ] Check weather and route.

### Day Before

- [ ] Charge devices.
- [ ] Pack personal and activity materials.
- [ ] Save offline maps and contacts.
- [ ] Share final agenda and contacts with the team.
- [ ] Prepare opening and closing notes.

### Event Day

- [ ] Check volunteers against the passenger list before departure.
- [ ] Arrive early.
- [ ] Greet host/local facilitator.
- [ ] Check venue setup and safety.
- [ ] Brief volunteers.
- [ ] Run the activity.
- [ ] Clean up and thank hosts.

### After the Event

- [ ] Count and return materials.
- [ ] Back up photos/videos.
- [ ] Write short event notes.
- [ ] Report issues or follow-up needs.
- [ ] Send selected documentation to the communication lead.

## 11. Volunteer Conduct Guidelines

- Treat community members as partners.
- Ask before taking close-up photos or videos.
- Use simple, respectful language.
- Follow local facilitator instructions.
- Do not make promises unless approved by the organizer.
- Keep sensitive comments out of public remarks.
- Leave the venue clean.
